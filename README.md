# Kentucky Permit Practice Test

**Take the practice test here (works on phones):**

## 👉 https://mrpiercey.github.io/driverstestpractice/

Each test has 40 questions with three answer choices each, like the real test: 30 rules-of-the-road questions and 10 road sign questions, drawn at random from a bank of 261 from the Kentucky Driver Manual. All 10 sign questions come before question 32. You need 32 correct (80 percent) to pass, same as the real permit test. The test ends early once you reach 32 correct or miss 9.

No sign-up, no app to install. Just open the link on any phone or computer and start answering. Tap **Take it again** at the end for a fresh set of questions.

The Kentucky Driver Manual is included in the `signs` folder for reference.
